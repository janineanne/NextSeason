# App Icon Artwork History

This folder contains the major SVG iterations created during the design
of the **NextSeason** app icon.

## Files

### `NextSeasonIcon-CoolGrayGradient.svg`

Introduced the final visual direction:

-   Cool gray vertical gradient background (`#F5F7F9` → `#E8EDF2`)
-   Teal TV and calendar artwork
-   Layered SVG suitable for importing into Apple's Icon Composer

This version looked good in isolation but, with **Liquid Glass Effects**
enabled, Icon Composer produced a noticeably strong blue band near the
bottom of the icon.

### `NextSeasonIcon-CoolGrayGradient-WhiteInteriors.svg`

Experimental variation.

Changes: - TV screen changed to near-white. - Calendar page changed to
near-white. - Calendar tab outlines changed to near-white.

The goal was to determine whether the interior colors were responsible
for the blue tint. Testing showed little or no improvement, so this
version was not adopted.

## Shipping Artwork

The shipping artwork is based on:

**`NextSeasonIcon-CoolGrayGradient.svg`**

with **Liquid Glass Effects disabled** in Icon Composer.

This combination produced the best overall appearance on the iOS Home
Screen:

-   subtle depth
-   no distracting blue band
-   clean utility-app aesthetic
-   strong TV + calendar recognition

## Notes

The SVG files are the editable source artwork.

The `.icon` package generated by Icon Composer is the production asset
used by Xcode.

Future revisions should be saved as new SVG files rather than replacing
existing ones so the design history is preserved.
