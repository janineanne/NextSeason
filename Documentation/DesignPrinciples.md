# Design Principles

## Philosophy

The app should feel like a standard Apple app.

Users should immediately understand how to use it.

## Rules

- Prefer standard iOS controls.
- Avoid custom controls.
- Minimize taps.
- Minimize screens.
- Favor readability over visual flair.
- Each screen should have one primary purpose.
- Accessibility is required.
- Use system colors and typography whenever possible.

- Prefer Apple's Human Interface Guidelines.
- Use standard navigation patterns.
- Every screen should have one primary purpose.
- Remove unnecessary controls.
- Favor clarity over visual novelty.
