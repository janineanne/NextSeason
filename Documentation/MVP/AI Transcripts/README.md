# AI Transcripts

This folder contains selected AI collaboration transcripts created during the development of NextSeason TV.  These transcripts have been lightly edited from the original AI conversations. Tool calls were removed for readability. All design discussions, technical reasoning, architectural decisions, and implementation guidance have been preserved.

These transcripts demonstrate how AI was used throughout the project for:

* architecture discussions
* implementation planning
* code generation
* code review
* debugging
* UI refinement
* accessibility
* testing
* release preparation

The files are organized chronologically by date.

ChatGPT transcripts primarily document design discussions, architectural guidance, and project reviews. Cursor transcripts document implementation sessions and the iterative development process. ChatGPT conversations are provided as PDFs, while Cursor conversations are provided as Markdown files.

These transcripts are included to document the AI-assisted development workflow and provide transparency into the design and implementation process.

Some transcript cleanup is still planned to remove unnecessary AI-generated boilerplate (such as tool invocation logs). The technical discussions themselves have not been edited and will remain unchanged.
